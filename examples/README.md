# Example scenarios

Illustrative values, not plant data. Calibration parameters are at their uncalibrated
defaults, so outputs are model predictions, not targets.

| File | Purpose | Used by |
|---|---|---|
| `reference_constant.toml` | Reference case: 10 t/h wet chips at 50 %, constant flue gas | quickstart §3, tests |
| `reference_timeseries.toml` | Same, flue gas as a constant time series | source swap test (SC-008), comparison |
| `step_feed_moisture.toml` | Feed moisture steps from 50 % to 55 % at 06:00, from steady state | quickstart §4 |
| `heat_limited.toml` | Flue gas reduced to 1.5 kg/s, no dilution air | quickstart §5 |
| `out_of_range_inlet.toml` | Flue gas at 950 °C from 08:00 to 10:00 | quickstart §5, range warnings |
| `invalid_flue_gas.toml` | Deliberately invalid input | quickstart §2 |
| `synthetic_measured.csv` | Synthetic measurements for `compare` | quickstart §8 |
| `boiler_house_only.toml` | 15 MW boiler house alone, oil 60 kg/s at 240 → 282 °C, steady start | feature 002 quickstart §3 |
| `oil_demand_step.toml` | Same, oil return 240 → 231.6 °C at 06:00 (+20 % oil heat demand) | quickstart §4, controller step test |
| `plant_reference.toml` | Boiler house feeding the reference dryer, drum inlet 540 °C | quickstart §5, coupling tests |
| `plant_oil_step.toml` | Coupled plant with the oil demand step | swap test (SC-006), balances |
| `synthetic_boiler_measured.csv` | Synthetic boiler house measurements for `compare` | boiler comparison test |
| `dryer_recirculation.toml` | Reference dryer with exhaust recirculation, mixing chamber at −200 Pa, steady start | feature 004 quickstart §2, tests |
| `data/controller_tuning.json` | Step-test fits and SIMC settings of the oil and O₂ loops | controller step test |

Feature-002 scenarios are described in
[docs/boiler_house.md](../docs/boiler_house.md); the dryer sections of the plant examples
are those of `reference_constant.toml`, unchanged.

## `synthetic_measured.csv`

Generated by `scripts/make_synthetic_measured.py` (seed 42) from the model's own prediction
for `reference_timeseries.toml`, sampled every 5 minutes (289 samples):

    measured = model + offset + noise

| Output | Offset | Noise (σ) | Expected bias (predicted − measured) | Expected RMSE |
|---|---|---|---|---|
| `product_moisture_wet_basis` | +0.004 | 0.002 | −0.004 | ≈ √(0.004² + 0.002²) = 0.0045 |
| `exhaust_temperature` | −2 K | 1 K | +2 K | ≈ √(2² + 1²) = 2.2 K |

Samples 20–22 and 150 are empty (missing), samples 60, 61 and 200 are flagged `bad` with
grossly wrong values, and the first sample has no product leaving the empty drum. All of
these must appear under `excluded` and must not affect the statistics. With the default
tolerances (±1 percentage point, ±5 K) both outputs pass.
